Advice that knows
when not to advise.

SmartAgri answers a farmer’s question about one maize parcel. Before any text is written, explicit rules decide whether it may recommend, give a conditional recommendation, ask a follow-up question, or abstain.

Four possible acts

The decision comes first.
The words come last.

The policy layer chooses one act from the data that are actually available and how reliable they are. A language model, when one is configured, only phrases the chosen act.

  • Recommend

    The inputs that matter for this type of advice are present and reliable enough. A quantity is given only when the rules allow it.

  • Conditional

    The answer depends on one missing fact. Each possible value of that fact gets its own consequence.

  • Ask

    One follow-up question, chosen because its answer would change the decision, with a note on how to find the answer in the field.

  • Abstain

    No recommendation, with the reason stated. Questions outside the system’s scope, or without support in the corpus, are referred to the extension service.

How it works

Deterministic layers
you can read and test.

Each layer is ordinary code with its own tests and a configuration file. Every answer keeps the decisions of each layer, so “Why?” has a concrete answer.

  1. C

    Context

    The parcel, its agronomic inputs, Open-Meteo weather and Sentinel-2 L2A NDVI, each with its date.

  2. π

    Applicability

    A deterministic filter over passage metadata: crop, growth stage, region, date and source type. No hidden model.

  3. q

    Quality

    Origin, age, coverage and reliability of every input. Missing inputs are listed, not filled in.

  4. σ

    Sufficiency

    Whether the inputs suffice for the requested type of advice, and which ones are missing.

  5. α

    Asking

    The next question: a missing input whose answer would change the decision, weighed against the effort to answer it.

  6. δ

    Policy

    The act: recommend, conditional, ask or abstain, with a reason code and whether a quantity is allowed.

  7. γ

    Grounding

    Checks the answer: numbers must come from the tools, sentences must be supported by the cited passages.

Numbers come from code

FAO-56, never the language model.

Crop water use, the water balance and irrigation doses are computed by tested functions. The default template generator needs no model, no key and no network access to one.

Interfaces

One core.
Three ways in.

The web app and the research API share one service. The evaluation harness calls the decision pipeline directly, so its results never depend on the web layer.

Draw a field. Ask a question.
See why.

  • Draw the parcel on a map, or paste and import GeoJSON
  • Fetch weather and Sentinel-2, with each input’s age and reliability
  • Ask under any variant V0–V5 and answer the follow-up question
  • Open “Why?” for the π, q, σ, α, δ and γ decisions and the provenance hashes
  • Blind rating of evaluation items, without variant labels

Light and dark themes, keyboard drawing, works on a phone. OpenStreetMap tiles are the only external request; the tile URL is configurable and drawing still works without tiles.

A small HTTP API
for local research use.

FastAPI, no accounts, bound to 127.0.0.1 by default. The OpenAPI schema is served at /docs.

  • Parcels and their input profile with quality q
  • Advisory conversation under a chosen variant
  • Every run stored with config, corpus and prompt hashes
  • Rubric and blinded rating queue
Terminalcommands, not output
python -m smartagri.research_api --port 8100

curl -s localhost:8100/api/health
curl -s -X POST localhost:8100/api/parcels \
  -H 'Content-Type: application/json' \
  -d @parcel.json            # name, sowing_date, geometry
curl -s -X POST localhost:8100/api/parcels/$ID/profile/refresh

  -H 'Content-Type: application/json' \

in one command line.

  • report automatic and rated measures, paired comparisons
  • guard n-gram leakage check between scenarios and corpus

Built to be checked,
not just believed.

Ablation ladder

Each variant adds to the previous one, so a paired comparison such as V4 against V3 isolates what those layers change. A free LLM conversation with the same data and passages (VC) is a baseline outside the ladder.

Blind rating

Raters score items on a five-criterion rubric with critical-error classes. They never see the variant, generator or model, and each rater gets a fixed item order.

Protocol lock

Before measurement, a lock file records the sha256 of the scenarios, corpus, configuration, prompts and rater guide. Held-out test scenarios are published only after the lock.

Provenance in every run

Each answer stores the configuration hashes, corpus hash, prompt hash, decision date and the satellite and forecast dates it used.

Limitations

A research prototype,
with clear edges.

  • One crop. Maize only.
  • One region. Rules, thresholds and passages are set for one reference region.
  • One language for answers. The corpus and the evaluation are in Serbian, so answers, sources and follow-up questions are in Serbian; the web app interface is in English.
  • Small corpus. Short paraphrases of FAO material with citations, plus development notes that are marked as not an expert source.
  • Not a substitute for an agronomist. The system can be wrong; it states its inputs and their reliability so that you can judge.
  • Optional services. Sentinel-2 needs Copernicus Data Space credentials; the VC chat needs a configured language model.

Get started

Running in a few minutes.
No keys needed.

Python 3.9 or newer. SQLite and offline mode by default; Docker is not required.

Linux / macOS
git clone https://github.com/ZeljkoDzafic/smartagri-core.git
cd smartagri-core/backend
python3 -m venv .venv && . .venv/bin/activate
pip install -c constraints-py39.txt -e ".[dev,api]"
pytest -q
python -m smartagri.research_api   # http://127.0.0.1:8100

On Python 3.12 use -c requirements.lock. On Windows, create the environment with py -m venv .venv and call .venv\Scripts\python.exe. Optional settings are listed in .env.example; set SMARTAGRI_TILE_URL to use another tile server, or none to turn tiles off.
