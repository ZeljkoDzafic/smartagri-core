# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to the issue tracker, pull requests, discussions and any other space of the
project, and to anyone who represents the project in public.

In short: be respectful and considerate, accept constructive criticism, focus on what is best for the people who
will use the advice this software produces, and do not harass, insult or publish others' private information.

## Reporting

Report unacceptable behaviour to the maintainer at **zeljkodzafic@gmail.com**. Reports are handled confidentially.
The maintainer will review each report and respond with the enforcement steps described in the Contributor Covenant
2.1 (correction, warning, temporary ban, permanent ban), in proportion to the behaviour.
